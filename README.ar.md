# نظام إرسال إيميلات التقديم على الوظائف

**العربية** · **[English](README.md)**

تطبيق سطح مكتب وواجهة أوامر ترسل رسائل تقديم **مخصّصة لكل شركة** من حسابك في
جيميل — **بالعربية أو الإنجليزية أو بهما معاً في رسالة واحدة** — ولا ترسل لشركة
واحدة مرتين أبداً.

---

## لماذا هذا النظام؟

مراسلة مئة شركة يدوياً تعني نسيان مَن راسلت، وإهمال المتابعة، وتصنيف حسابك كمرسل
سبام. هذا يحل الثلاثة.

| المشكلة | الحل |
|---|---|
| نسيان مَن راسلت | سجل SQLite — **الإرسال مرتين لنفس الشركة مستحيل**، حتى لو انقطع التشغيل في منتصفه |
| الوقوع في السبام | فواصل عشوائية وحد يومي ونافذة زمنية، مع **فحص خطر قبل كل إرسال** |
| رسائل عامة يتجاهلها الجميع | اسم الشركة وجهة الاتصال وسطر مخصص لكل واحدة — بمعاينة حيّة أثناء الكتابة |
| نسيان المتابعة | يعرف مَن مضى على رسالته 7 أيام ولم يردّ، ويضع المتابعة داخل نفس المحادثة |
| العناوين الميتة تحرق سمعتك | **فحص سجلات MX قبل الإرسال** يكشف ما سيرتد |
| عدم معرفة مَن ردّ | يزامن مع جيميل ويفرز الردود البشرية عن إشعارات الارتداد |

العربية مواطن من الدرجة الأولى: قوالب RTL، واتجاه صحيح لكل فقرة في الرسائل
المختلطة، وواجهة عربية بالكامل.

---

## الأقسام

التطبيق سبعة أقسام. المكان الذي ستقضي فيه وقتك هو **الشركات ← تفاصيل**، حيث تكتب
السطر المخصص لكل شركة وترى الرسالة تتغير أمامك.

```
الحالة        ← ماذا تفعل الآن، مرتباً بالأولوية
الشركات       ← جدول قابل للتعديل + لوح تفاصيل بمعاينة حيّة
المعاينة      ← الرسالة كما ستصل الشركة تماماً
الإرسال       ← العدد والمدة وفحص السبام والتأكيد وسجل مباشر وزر إيقاف
الردود        ← مَن ردّ، وأي مسودة أرسلتها بيدك
السجل         ← كل عملية سجّلها النظام
الإعدادات     ← نصوص الرسالة وإيقاع الإرسال دون فتح YAML
```

## المتطلبات

- **ويندوز** (التطبيق يستخدم Edge WebView2 المثبّت مسبقاً على ويندوز 11)

## التثبيت

```powershell
git clone https://github.com/<you>/job-outreach.git
cd job-outreach
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py init
```

أمر `init` ينسخ `config/*.example.yaml` إلى ملفات إعداداتك وينشئ المجلدات.
**إعداداتك وسيرتك الذاتية وقائمة شركاتك وسجل إرسالك كلها مستثناة في `.gitignore`**
ولا تغادر جهازك.

## إعداد Gmail API (مرة واحدة، ~10 دقائق)

1. افتح [Google Cloud Console](https://console.cloud.google.com/) وسجّل الدخول
   بحساب جيميل الذي سترسل منه
2. أنشئ مشروعاً
3. **APIs & Services ← Library** ← ابحث عن **Gmail API** ← **Enable**
4. **Google Auth Platform ← Audience**
   - نوع المستخدم: **External**
   - إما تضيف إيميلك في **Test users**، أو تضغط **Publish**
   - ⚠️ في وضع *Testing* يُبطل جوجل التوكن كل 7 أيام. النشر يتجنب ذلك (وستظهر
     شاشة «تطبيق غير موثّق» تتجاوزها بـ Advanced ← Go to)
5. **Credentials ← Create Credentials ← OAuth client ID ← Desktop app** ← حمّل ملف JSON
6. ضع الملف في مجلد `config/` — بلا إعادة تسمية، فالنظام يتعرف على اسم جوجل
   الافتراضي `client_secret*.json`
7. شغّل:

```powershell
python main.py auth
```

## املأ بياناتك

**1. سيرتك الذاتية** ← `attachments/CV.pdf` (غيّر الاسم في `config/settings.yaml`
إن اختلف)

**2. `config/profile.yaml`** — كل حقل يظهر داخل رسائلك. أي قيمة تبدأ بـ `TODO`
تمنع الإرسال. وأهم حقل هو `achievement_ar` / `achievement_en`:

> ❌ «لدي خبرة جيدة في تطوير المواقع»
> ✅ «بنيت متجر shop.com بالعربية مع نظام دفع بمعاملات ذرية ونشر آلي عبر GitHub Actions»

**3. `config/settings.yaml`** — اسمك وإيميل الإرسال.

**4. الشركات** ← `data/companies.csv`:

| العمود | إلزامي | الوصف |
|---|:---:|---|
| `company_name` | ✅ | يظهر داخل نص الرسالة |
| `email` | ✅ | وجهة الإرسال |
| `contact_name` | — | يحوّل «تحية طيبة» إلى اسم — يرفع نسبة الرد بوضوح |
| `role_target` | — | الوظيفة في عنوان الرسالة |
| `language` | — | `ar` أو `en` أو `both` (الافتراضي `en`) |
| `custom_note` | — | سطر يخص هذه الشركة وحدها — أقوى ما يمكنك إضافته |
| `website` | — | للمرجع فقط |
| `attachments` | — | مرفقات خاصة مفصولة بـ `;` |
| `skip` | — | ضع `1` للتجاوز |

انظر `data/companies.example.csv`. وللاستيراد الجماعي الصق القائمة في التطبيق، أو:

```powershell
python main.py import emails.txt --language both
```

**5. الفحص الشامل:**

```powershell
python main.py validate
```

## الاستخدام

**تطبيق سطح المكتب** — انقر نقرة مزدوجة على `تشغيل النظام.vbs`، أو أنشئ اختصاراً
على سطح المكتب بـ `انشاء اختصار على سطح المكتب.vbs`.

**واجهة الأوامر:**

```powershell
python main.py check-domains        # يكشف العناوين التي سترتدّ
python main.py check-domains --skip # ويتجاوزها
python main.py dedupe               # إزالة الإيميلات المكررة
python main.py preview --limit 3    # معاينات HTML في previews/

python main.py send --draft --limit 3   # بروفة آمنة: مسودات في جيميل
python main.py send --dry-run           # عرض الخطة فقط
python main.py send --limit 10          # الإرسال الفعلي

python main.py check-replies        # مَن ردّ + حسم مصير المسودات
python main.py followup             # متابعة مَن لم يردّ
python main.py status
```

خيارات مشتركة لـ `send` و`followup`: `--limit N` و`--draft` و`--dry-run`
و`--yes` و`--force` و`--ignore-schedule`.

## الحماية من السبام

مضبوطة في `config/settings.yaml` تحت `sending`:

- **حد يومي** (افتراضي 40) يُحسب على آخر 24 ساعة متحركة
- **فاصل عشوائي 45–120 ثانية** — الفاصل **الثابت** نمط آلي مكشوف بذاته
- **استراحة 5 دقائق** بعد كل 10 رسائل
- **نافذة زمنية** 8ص–6م مع تخطي الجمعة والسبت

و**فحص خطر يعمل قبل كل إرسال** يقيس ما يهم فعلاً:

| ما يفحصه | لماذا |
|---|---|
| نسبة الارتداد | أقوى إشارة سبام — القوائم الميتة بصمة المرسل المزعج |
| نطاقات بلا سجل MX | ارتداد مؤكد، يُكشف قبل الإرسال |
| رسائل بلا سطر مخصص | التطابق شبه التام لعشرات المستقبلين يُقرأ إرسالاً جماعياً |
| الملاحظة المكررة | تفقد غرضها عند الفلتر وعند القارئ معاً |
| الفاصل والحد اليومي | إيقاع الآلة يفضح نفسه |
| عدد الروابط والكلمات المحفزة والأحرف الكبيرة | أوزان تقليدية في الفلاتر |

> الفحص **إرشادي ولا يمنع الإرسال**. وهو **لا يعدّل نصك**: تدوير المرادفات لخداع
> المصنّف تقنية سبام معروفة، والفلاتر تكشف نمط التدوير نفسه — فيصير التمويه دليل
> إدانة.

## القوالب

في `templates/{ar,en,both}/{initial,followup}.md`. الصيغة:

```
subject: "عنوان الرسالة — يقبل متغيرات"
---
نص الرسالة
```

المتغيرات المتاحة:

| المتغير | المعنى |
|---|---|
| `{{ me.* }}` | أي حقل من `profile.yaml` |
| `{{ company_name }}` `{{ contact_name }}` `{{ role_target }}` | من ملف CSV |
| `{{ custom_note }}` `{{ website }}` | من ملف CSV |
| `{{ attachment_names }}` | أسماء المرفقات |
| `{{ today }}` `{{ initial_sent_date }}` | التواريخ (الثاني لقوالب المتابعة) |

الأسطر التي تبدأ بـ `- ` تصير قوائم نقطية في نسخة HTML، والروابط تصير قابلة
للنقر، والعربية تُضبط بـ `dir="rtl"` تلقائياً. وكل رسالة تُرسل بنسختين — نص صِرف
وHTML — داخل ظرف واحد.

## الأمان

- ملفات الاعتماد والتوكن والسيرة وقائمة الشركات وسجل الإرسال كلها مستثناة في `.gitignore`
- الصلاحيات المطلوبة من جوجل: `gmail.compose` (إرسال ومسودات) و`gmail.readonly`
  (كشف الردود). **لا صلاحية حذف.**
- لإلغاء الوصول في أي وقت: [myaccount.google.com/permissions](https://myaccount.google.com/permissions)

## حل المشاكل

| العَرَض | الحل |
|---|---|
| `ModuleNotFoundError` | أنت على بايثون النظام — فعّل البيئة، أو استخدم `.\.venv\Scripts\python.exe main.py …` |
| `Activate.ps1 … disabled` | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `access_denied 403` | أضف إيميلك في **Test users**، أو انشر التطبيق |
| التوكن ينتهي كل 7 أيام | وضع Testing يُبطله أسبوعياً — انشر التطبيق أو أعد `auth` |
| العربية مشوّهة في الطرفية | `chcp 65001` |
| التطبيق لا يفتح | افحص `data/app_error.log` |
| توقف التشغيل في المنتصف | أعد نفس الأمر — يكمل ولا يكرر أي شركة |

## ملاحظة عن الاستخدام المسؤول

هذا النظام يرسل **طلبات توظيفك أنت من حسابك أنت**. ليس أداة إرسال جماعي: الحد
اليومي والإيقاع البطيء وفحص الخطر موجودة لتبقيه كذلك. لا تستخدمه لمراسلة من لم
يدعُ للتواصل، ولا تنشر قوائم عناوين مجمّعة — ولهذا `data/companies.csv` مستثنى
في `.gitignore`.
